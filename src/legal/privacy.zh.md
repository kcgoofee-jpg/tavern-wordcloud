## 2. 各类数据的实际处理方式

### 2.1 您上传的聊天正文

- **网页版：** 正文传输至服务器后**仅在内存中处理，处理完立即丢弃**，不写入磁盘，不记入日志。
- **单文件离线版：** 全部处理在您自己的浏览器内完成，数据不离开您的设备。
- **关键词模式与大模型分词：** 经清洗的正文会被发送至**您自行指定**的大语言模型接口地址（可能经本服务的服务器中转，仅在内存中过境，不予记录）。本服务自身不提供任何模型密钥。该供应商自身的隐私政策适用于该等传输。

### 2.2 访问日志

每次请求记录一行：时间、请求方法、路径（**不含查询字符串**）、状态码、耗时、响应大小及**您 IP 地址的加盐哈希（不可逆）**。不记录请求正文，不记录 User-Agent。日志保存在服务器上，仅运营者可查阅，用于运行维护及识别滥用。**访问日志最长保留 90 天，到期自动删除。**

### 2.3 浏览器错误自动上报

页面发生脚本错误时，浏览器自动发送：错误消息（不超过 500 字符）、错误堆栈（不超过 2000 字符）、页面路径及浏览器 User-Agent（不超过 200 字符），服务端另附记**您 IP 地址的加盐哈希（不可逆）**。聊天正文与词表绝不包含在内，但堆栈中可能偶然带有文件路径或代码片段。此类记录最长保留 90 天。

### 2.4 社区统计贡献（可选，默认开启）

每次分析完成后发送一份结构化数据：高频词前 100 个及其次数（不含人名、不含露骨词）、消息条数、字数及中文词占比。同时包含您所选模型的名称与接口类型（仅为「厂商官方／OpenRouter／第三方中转／本机／其他」这一粗略分类，**不含接口地址，也不含任何密钥**）。另包含界面偏好：所选配色与字体的标识、色觉设置、是否使用了自定义功能（布尔值与数量区间）。若您在「检查分类」或词频表面板里手动更正过某些词的分类，也会一并发送：您手动更正过的词及其类别（仅词与类别标识，不含上下文），最多 50 条。**绝不包含聊天正文，也不包含角色卡名称。** 您应仅在有权分享该记录统计信息时参与。 本功能不存储您的原始 IP 地址，而以不可逆的加盐哈希值代替；如未配置固定盐值，则盐值随服务器进程随机生成，进程重启后即变，从而进一步削弱可关联性。聚合数据仅在某词被至少 3 名不同贡献者共有时才对外公开。

您可随时在「社区排行榜」面板关闭此功能；关闭后不再发送任何贡献数据。

### 2.5 清洗反馈（仅在您明确发送时）

点击词频表中的「不该出现」按钮后，页面会**先向您展示**将从清洗后文本中提取的至多 3 段上下文片段（每段不超过 160 字符），**经您确认后**才连同该词及您 IP 地址的加盐哈希（不可逆）一并发送。**该等片段是您聊天内容的残片，将保存在服务器上，用于修正清洗规则。** 这是本服务唯一留存您内容片段的情形。

### 2.6 浏览器本地存储

本服务不使用 Cookie 进行追踪。您的设置（语言、主题、分析选项、社区贡献开关）仅保存于您浏览器的本地存储（localStorage）中。**如您配置了大语言模型 API 密钥，该密钥以明文形式保存于本地存储。** 在公用或共享设备上使用后，请自行清除。

### 2.7 自部署访问统计

本服务使用与服务器同机部署的开源统计软件（Matomo）记录页面浏览与错误事件，**已禁用 Cookie**，不向任何第三方分析公司发送数据。

### 2.8 基础设施第三方

您的请求必然经过服务器托管商及 [Cloudflare](https://www.cloudflare.com/privacypolicy/)（内容分发与安全防护），它们依其自身隐私政策处理您的 IP 地址及完整请求 URL。大语言模型供应商仅按第 2.1 条所述接收文本。对该等第三方所持数据的请求，应直接向该第三方提出。

### 2.9 导出文件与分享链接

导出的 PNG 图像内嵌词表与配色设置；CSV 文件包含完整词表。分享链接的数据位于网址片段（「#」之后），不会发送至服务器。以上均不含用户名、角色卡名或聊天正文。文件一经导出，即完全由您自行保管。
