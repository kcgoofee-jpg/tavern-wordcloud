## 2. 各类数据的实际处理方式

### 2.1 您上传的聊天正文

- **网页版：** 在服务端可达时，单个、且无需套用自定义清洗正则的聊天文件会被上传并在服务端分析：正文**仅在内存中处理，处理完立即丢弃**，不写入磁盘，不记入日志；请求离开浏览器前，您的模型密钥与自定义清洗正则已被剔除。整包 `.zip` 备份、一次选中多个文件、或需要套用您自定义清洗正则的分析，**改在您的浏览器内完成**，该等正文不离开您的设备。
- **单文件离线版：** 全部处理在您自己的浏览器内完成，聊天正文、词表与使用记录均不离开您的设备。「不离开设备」的唯一例外是第 2.8 条所述的网络字体，且仅在您主动选用该字体时发生。
- **关键词模式与大模型分词：** 经清洗的正文会被发送至**您自行指定**的大语言模型接口地址（可能经本服务的服务器中转，仅在内存中过境，不予记录）。本服务自身不提供任何模型密钥。该供应商自身的隐私政策适用于该等传输。

### 2.2 访问日志

每次请求记录一行：时间、请求方法、路径（**不含查询字符串**）、状态码、耗时、响应大小及**您 IP 地址的加盐哈希（不可逆）**。不记录请求正文，不记录 User-Agent。日志保存在服务器上，仅运营者可查阅，用于运行维护及识别滥用。**访问日志最长保留 90 天，到期自动删除。**

服务端进程会把同样的字段写入自身的控制台输出，其中同样是加盐哈希而非原始地址。运营者在应对攻击期间可临时开启原始地址输出；该输出始终不写入本服务的数据存储，服务端进程被替换后即不复存在。

### 2.3 浏览器错误自动上报

页面发生脚本错误时，浏览器自动发送：错误消息（不超过 500 字符）、错误堆栈（不超过 2000 字符）、页面路径及浏览器 User-Agent（不超过 200 字符），服务端另附记**您 IP 地址的加盐哈希（不可逆）**。聊天正文与词表绝不包含在内，但堆栈中可能偶然带有文件路径或代码片段。服务端内存中至多保留最近 200 条；落盘的记录超过 90 天即自动删除。

### 2.4 社区统计贡献（可选，默认开启）

每次分析完成后发送一份结构化数据，内容为：

- 高频词前 100 个及其次数——被本服务判定为人名、常见词或露骨词的词在发送前即被剔除，服务端在对外公开前再执行一次人名过滤；
- 消息条数、字数及中文词占比；
- 各词类下的词数；
- 您所选模型的名称与接口类型（仅为「厂商官方／OpenRouter／第三方中转／本机／其他」这一粗略分类，**不含接口地址，也不含任何密钥**）；
- 若聊天记录自身载有生成耗时，则包含其中位数（毫秒）；
- 若您导入的是整包备份，则包含其中角色卡与世界书的数量、以及是否含有预设——**仅为数量与是非值，绝不含角色卡、预设或世界书的名称**；
- 界面偏好：所选配色与字体的标识（自行导入的字体一律记为字面量 `custom`，绝不记录其文件名或字族名）、色觉设置、是否使用了自定义功能（布尔值与数量区间）；
- 若您在「检查分类」或词频表面板里手动更正过某些词的分类，则包含您更正过的词及其类别（仅词与两个类别标识，不含上下文），最多 50 条。

**绝不包含聊天正文，也不包含角色卡名称。** 您应仅在有权分享该记录统计信息时参与。本功能不存储您的原始 IP 地址，而以不可逆的加盐哈希值代替；如未配置固定盐值，则盐值随服务器进程随机生成，进程重启后即变，从而进一步削弱可关联性。服务端对同一地址每日至多接受 20 次贡献。

**何者公开、何者不公开。** 某个词、某个模型名称或某个接口类型，仅在至少 3 名不同贡献者报告过它时才出现在公开的社区榜单上，低于该门槛的一律并入单独的「其他」一行。词类占比、聊天体量分布与时段分布仅以总量形式公开。词类更正与界面偏好**绝不**公开，仅运营者可见。运营者自身的贡献不计入任何对外公开的聚合数据。

您可随时在「社区排行榜」面板关闭此功能；关闭后不再发送任何贡献数据。

### 2.5 清洗反馈（仅在您明确发送时）

点击词频表中的「不该出现」按钮后，页面会**先向您展示**将从清洗后文本中提取的至多 3 段上下文片段（每段不超过 160 字符），**经您确认后**才连同该词及您 IP 地址的加盐哈希（不可逆）一并发送。**该等片段是您聊天内容的残片，将保存在服务器上，用于修正清洗规则。** 这是本服务唯一留存您内容片段的情形。

### 2.6 浏览器本地存储

本服务不使用 Cookie 进行追踪，亦不向普通访客下发任何 Cookie。本服务唯一会设置的 Cookie 是运营者自身后台管理页面的会话 Cookie，仅在口令登录后签发，有效期 8 小时。您的设置（语言、主题、分析选项、社区贡献开关）仅保存于您浏览器的本地存储（localStorage）中。**如您配置了大语言模型 API 密钥，该密钥以明文形式保存于本地存储。** 在公用或共享设备上使用后，请自行清除。

### 2.7 访问统计

本服务**不运行任何统计分析软件**（无论自部署与否），页面中亦不嵌入任何第三方分析或广告脚本。运营者所见的页面浏览与报错数字，全部来自第 2.2 条的访问日志与第 2.3 条的错误上报，别无他途。本服务的早期版本曾嵌入一套自部署、不使用 Cookie 的统计探针，该探针已停用，且不再随页面下发。

### 2.8 基础设施第三方

您的请求必然经过服务器托管商及 [Cloudflare](https://www.cloudflare.com/privacypolicy/)（内容分发与安全防护），它们依其自身隐私政策处理您的 IP 地址及完整请求 URL。大语言模型供应商仅按第 2.1 条所述接收文本。对该等第三方所持数据的请求，应直接向该第三方提出。

**网络字体。** 若您在字体面板中选用繁体中文网络字体，您的浏览器会向 [Google Fonts](https://policies.google.com/privacy) 请求该字体的样式表，该第三方由此获得您的 IP 地址与 User-Agent。此情形仅在您作出该项选择时发生，在单文件离线版中同样发生，且不涉及任何聊天正文、词表或其他内容。除此之外，本服务的任何字体与任何功能都不会连接运营者选定的第三方。

### 2.9 导出文件与分享链接

导出的 PNG 图像内嵌词表与配色设置；CSV 文件包含完整词表。分享链接的数据位于网址片段（「#」之后），不会发送至服务器。以上文件内容均不含用户名、角色卡名或聊天正文。但**默认文件名由角色卡名称构成**；您可在导出面板的文件名模板中于保存前自行更改。文件一经导出，即完全由您自行保管。

### 2.10 作者认领（仅在您主动提交时）

若您希望自己创作的角色卡在社区榜单上得到标注，认领表单会发送：卡名、您用以证明作者身份的公开链接、本站为您生成的校验串，以及您 IP 地址的加盐哈希（不可逆）。该记录保存在服务器上直至运营者作出处理，不会自动删除。认领待决期间不公开任何内容；若运营者通过认领，则**该卡名会在社区榜单上作为「已认领」公开**。您提交的链接本就是您已公开的页面。请勿提交身份证件、聊天记录或角色卡文件。
