# 执法与法律请求政策

**酒馆词云（tavern-wordcloud）** · https://wordcloud.davidzhao.top

生效日期：2026 年 9 月 4 日 ｜ 最近更新：2026 年 9 月 4 日

> 本文件提供中文与英文两种版本。两种版本如有歧义，以英文版本为准。本政策是[《服务条款》](#/terms)与[《隐私政策》](#/privacy)的组成部分。

本政策说明本服务实际留存何种数据、不存在亦不留存何种数据，以及运营者如何处理来自执法机关、监管机构、法院及私人主体的请求。本政策是对实际做法的公开陈述，也是运营者在回应任何问询时将出示的文件。**本政策不为任何第三方创设权利，亦不在适用法律之外为运营者增设任何义务。**

## 1. 设计前提：数据最小化

本服务经刻意设计，使**通常会被调取的数据类别大多根本不存在**。运营者无法提供其不持有的数据。具体而言，本服务：

- **没有用户账号**——无注册、无用户名、无密码、无电子邮箱、无真实姓名；
- **不存储聊天正文**——上传的文本在服务器内存中处理，返回结果后立即丢弃，从不写入磁盘或日志；
- **日志不含请求正文**——访问日志不含提交内容、不含查询字符串、不含 User-Agent，且以 IP 地址的加盐哈希（不可逆）为键，而非原始 IP 地址；
- **不使用追踪 Cookie 或跨站标识符**；
- **没有支付数据**——本服务免费，不发生任何交易。

## 2. 确实存在的数据

| 数据类别 | 内容 | 标识符 | 保留期限 |
|---|---|---|---|
| 访问日志 | 每请求一行：时间、方法、路径（不含查询字符串）、状态码、耗时、响应大小、IP 地址的加盐哈希（不可逆） | IP 地址的加盐哈希（不可逆） | 90 天，到期自动删除 |
| 浏览器错误报告 | 错误消息（≤500 字符）、堆栈（≤2000 字符）、页面路径、User-Agent（≤200 字符） | IP 地址的加盐哈希（不可逆） | 90 天，到期自动删除 |
| 清洗反馈 | 被反馈的词，及用户明确确认后发送的至多 3 段上下文片段（每段 ≤160 字符） | IP 地址的加盐哈希（不可逆） | 至人工处理完毕；轮转文件 90 天自动删除 |
| 社区贡献 | 高频词前 100 个及次数、消息数、字数、中文词占比（不含角色卡名称） | IP 地址的加盐 SHA-256 哈希（16 位十六进制） | 无固定期限（聚合数据） |

补充说明：

- 社区标识哈希使用运营者配置的盐值；**未配置时，盐值随服务器进程随机生成，进程重启即变**，因此即使运营者本人亦无法跨重启关联贡献记录；在无针对已知 IP 地址进行原像搜索的情况下，亦无法从哈希值反推 IP 地址。
- 社区聚合数据仅在条目被至少 3 个不同哈希标识共有时才对外公开。
- 第三方基础设施（服务器托管商、[Cloudflare](https://www.cloudflare.com/privacypolicy/)）独立持有网络层日志，包括完整 URL 与 IP 地址，适用其自身的保留政策。**对该等数据的请求应直接向相应第三方提出。**

## 3. 法律请求的处理

3.1 **强制披露。** 仅当对运营者适用的司法辖区的有效法律程序（例如法院命令或具有约束力的传票）要求时，运营者才会披露第 2 条所列数据，且仅以被要求的范围为限。

3.2 **限缩原则。** 对于范围过宽、缺乏管辖依据或索要根本不存在之数据的请求，运营者将参照本政策如实答复，并保留提出异议的权利。

3.3 **不主动批量披露。** 除有效法律程序及第 4 条所述紧急情形外，运营者不主动向任何一方提供留存数据。

3.4 **数据保全。** 收到有权机关的有效保全请求后，运营者将尽合理努力保全现有的第 2 条所列数据，期限不超过 90 天，以待正式法律程序。已在常规运维中删除的数据无法恢复。

3.5 **通知用户。** 在法律允许的范围内，运营者倾向于通知受影响的用户；但由于留存数据通常无法识别到具体用户，实际上一般无法通知。

3.6 **费用。** 运营者为响应法律请求而产生的合理费用，在适用法律允许的范围内，保留向请求方索偿的权利。

## 4. 紧急情形与儿童安全

4.1 **紧急披露。** 运营者基于善意认为披露对防止迫在眉睫的死亡或严重人身伤害所必需时，可不经事先法律程序向有关当局披露留存数据。

4.2 **儿童性虐待材料（CSAM）。** 本服务对此采取零容忍政策（见[《内容与可接受使用政策》](#/content)）。由于本服务不托管、不存储用户内容，相关情形一般仅涉及反馈片段或社区聚合数据；疑似材料将被移除，并可能依据 [18 U.S.C. § 2258A](https://www.law.cornell.edu/uscode/text/18/2258A) 等适用法律向美国国家失踪与受虐儿童中心（[NCMEC](https://report.cybertip.org/)）或当地相应机构报告。

## 5. 实际效果说明

请求方实际可能获得的数据至多包括：以 IP 地址的加盐哈希（不可逆）为键的访问日志（仅能表明某哈希标识访问过哪些路径，不能表明处理了何种内容，也无法直接反推原始 IP 地址）、错误记录、反馈片段及哈希化的社区聚合数据。**本服务所处理的实质内容无法从运营者处获得，因为该内容从未被存储。** 但下列内容可能从运营者控制范围之外的主体处获得：用户自己的设备（浏览器本地存储、导出文件）、用户自行配置的大语言模型供应商、服务器托管商及 Cloudflare。
