# 使用手册

原理（解析、清洗、分词怎么做，接了 API 会发什么）见仓库首页 [README](../README.zh.md)。这里只讲怎么用。

两种用法，**区别只有一个：聊天记录去不去服务器。**

| | 本地版 | 网页版 |
|---|---|---|
| 地址 | 自己电脑上的一个文件 | https://wordcloud.davidzhao.top |
| 正文去哪 | 不出网 | 上传到服务器处理，处理完即丢弃 |
| 关键词模式（大模型挑词） | 填自己的接口，浏览器直连（部分供应商不开跨域会失败） | 填自己的接口，服务器帮你中转（不开跨域时） |
| 安装 | 一条命令，或下载一个文件 | 不用 |

## 本地版

macOS / Linux，打开终端粘贴：

```bash
curl -fsSL https://wordcloud.davidzhao.top/install.sh | sh
```

Windows，打开 PowerShell 粘贴：

```powershell
irm https://wordcloud.davidzhao.top/install.ps1 | iex
```

做了什么：把线上同一份单文件 `index.html` 下载到 `~/tavern-wordcloud/`，然后打开浏览器。以后再用：终端输入 `tavern-wordcloud`，或者直接双击那个 `index.html`。不想装脚本：直接下载 https://wordcloud.davidzhao.top/download/index.html 双击打开。

本地版打开后所有处理都在你的浏览器里，断网也能用。界面和网页版一样，只是入口那行字写的是「所有处理都在这台电脑上，不出网」，也没有社区排行榜。

## 网页版

打开 https://wordcloud.davidzhao.top ，先看到示例词云，点任意位置进入导入页。其余与本地版相同。

## 界面

1. 把酒馆导出的文件拖进导入页。支持：
   - 单份聊天 `.jsonl` / `.json`
   - 「导出为纯文本」的 `.txt`
   - 酒馆「备份 → 导出整包」的 `.zip`（推荐：世界书和角色卡里的关键词会当专名词典，人名切得更准；设置和角色卡里的正则脚本会自动用来清洗）
   - 酒馆「正则」扩展导出的 `regex-*.json`：脚本里描述的状态栏、思维链、选项等格式会被直接删掉，比通用规则准得多。可以和聊天记录一起拖进来
   - 本站导出的词云 `.png`：拖回来直接复现
2. 默认统计**你和角色**说的话。只想看自己写的，在导入确认页或左侧「筛选」面板里取消「角色说的」。酒馆自己插入的系统消息始终不算。
3. 左侧图标从上到下：导入、筛选与分词、词频表、高级设置、大模型接口、导出、清空。
4. 左下角：配色、字体、这份聊天的信息（角色卡、模型、字数、时间）。
5. 右上角：站内通知（仅网页版，站长发了公告才出现，带小圆点表示还没看过）、社区排行榜（仅网页版）、语言、深浅色。

**筛选与分词**里的词类按钮：其他 / 人名 / 地点 / 时间 / 常见词。人名默认不显示（频率远高于其他词）；「常见词」是在所有消息里均匀出现、不属于这个故事的词，默认也不显示，点一下就回来。按钮下方「看看各类都有哪些词」能展开每一类被归进去的词和次数，方便核对是不是误判。

消息计数：用 `/hide` 隐藏过的消息仍按原说话人统计（酒馆把它们标成 is_system，但那是你和角色的话），真正的系统通知不计。

**导出**（左栏图标）是一个面板：

- 图片：清晰度 1×/2×/3×（面板里直接显示像素尺寸）、透明背景开关、是否在图里嵌入词表和配色。嵌了词表的 PNG 拖回网页就能原样复现，不需要原始记录，也可以把图发给别人让他复现。
- 词表：CSV 可选「只要显示中的词」或「全部词」，带 BOM，Excel 直接打开不乱码；列为词、次数、词类。
- 文件名统一为 `酒馆词云_<角色卡>_<词频|关键词>_<日期-时间>_<N>词.png`（词表以 `_词表.csv` 结尾），英文界面下为 `wordcloud_…`。

**社区排行榜**（右上角柱状图图标，仅网页版）：点一次看排行榜和聚合统计，再点一次只看社区词云，再点一次回到自己的词云。排行榜只统计合并词云（高频词及次数、条数字数），不收集也不展示角色卡名；请仅在您有权分享这份记录的统计时参与。

**关键词模式**（顶上切换）：让大模型读完整份聊天挑出"这个故事独有的词"，一次请求、一到五分钟。无论网页版还是本地版，都要先在「大模型接口」面板填自己的地址、模型、密钥；网页版只是在需要时用服务器帮你中转请求。

### 填了自己的接口会发生什么

| 功能 | 何时触发 | 发出去什么 | 收回什么 |
|---|---|---|---|
| 拉取模型列表 | 点「拉取可选模型」 | 只带密钥的 GET /models | 模型名列表 |
| 关键词模式 | 点「开始挑词」 | 一条提示 + 清洗后的全文 | 一行一个词；原文里没有的丢掉 |
| 大模型分词 | 面板里勾选并手动运行 | 切词规则 + 每块 ≤1200 字的正文 | 每块一个 JSON 数组；拼不回原文的块退回本地分词 |
| 写清洗规则 | 点「写规则」 | 提示 + 至多 5 条原文（每条 ≤2500 字） | 正则数组，先在样本上试过才用 |

密钥只存在你浏览器里；网页版经本站中转只转发地址、请求体和密钥头，不存任何东西。完整说明见 README 的「使用你自己的 API 密钥时」。

## 清洗规则从哪来

词云里不该出现插件写进正文的东西（状态栏、变量块、选项、思维链）。清洗分四层，都不用配置：

1. 结构规则：非标准标签整块删、网页代码、裸 JSON、键值状态块、折叠摘要。
2. 你自己的正则脚本：拖进 `regex-*.json` 或整包 `.zip`，脚本匹配的就是你这套预设让模型输出的格式。
3. 统计规则：同一行在大多数消息里都出现、或某个词在大多数消息的开头/结尾恰好出现一次，视为模板。
4. 禁词表：站长维护的手动表、自动表，高级设置里可关。

词频表里某个词不该出现时，点它旁边的 ⚠ 提交反馈，站方定期处理并更新规则。

## 常见问题

**词云几乎是空的。** 你和角色说的默认都算。如果你在「筛选」里只留了「我说的」，新开的聊天可能只有几句话——会弹提示，点「加上角色说的」。

**词云里有「那只」「一股」「极度」「后方」这种词。** 这类指示词+量词、程度副词、方位词已经进了停用词表；还剩下的，在词频表里点 × 隐藏，并欢迎点 ⚠ 反馈。均匀出现在所有消息里的词会被归到「常见词」类，默认不显示。

**词云里有 insert、path、value 这种词。** 插件把变量补丁写进了正文。已经会自动清掉；还有漏网的话，在词频表里点那个词旁边的 × 隐藏，并欢迎反馈。

**人名被切碎了。** 拖整包 `.zip`，世界书和角色卡关键词会当词典；或在高级设置的「强制成词」里加上它。

**拉不到模型列表 / Failed to fetch。** 网页版：地址填基址也行（会自动补 `/chat/completions`），模型名从「拉取可选模型」里选。本地版：那家接口不开跨域时浏览器直连会失败，换网页版或换供应商。

**推理模型很慢。** 会先"思考"的模型一块要近一分钟，挑词可能超过五分钟。换 DeepSeek-V4-Flash 这类快的。

**隐私。** 网页版上传的正文处理完即丢，服务器不存文件、不记正文；需要绝对不出网就用本地版。详见[隐私政策](https://wordcloud.davidzhao.top/#/privacy)。
